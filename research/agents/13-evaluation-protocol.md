# Evaluation Protocol

- **Meta-World+**: Pin version + reward version
- **10 seeds minimum**, 50 episodes per task
- **IQM with 95% bootstrap CI** (not just mean)
- **Per-task breakdown** always
- **Path efficiency + smoothness** alongside success rate
- **Binary success**: object within 5cm of goal
- **V1 vs V2**: 100x scale difference, not comparable
- **SE at n=10: ±16%** (unacceptable), n=500: ±2% (good)
